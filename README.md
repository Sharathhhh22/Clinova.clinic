# Clinova - Doctor Clinic & Healthcare Website

A modern, responsive, and performance-optimized healthcare & medical clinic website inspired by Clinova. Built with clean semantic HTML5, modern Tailwind CSS architecture, and smooth motion interactions.

## 🚀 Live Demo & Deployment
Easily deployed to [Vercel](https://vercel.com/) with zero configuration.

### Features
- **Smooth Lenis Scroll**: Momentum scrolling for fluid navigation.
- **Glassmorphism Navbar**: Adaptive sticky navigation with mobile drawer support.
- **Hero & Dynamic Statistics Marquee**: Infinite continuous 60fps ticker highlighting practice milestones.
- **Services Showcase**: 6 comprehensive clinical specialties with interactive hover states.
- **Video Testimonial Lightbox**: Video modal integration for patient success stories.
- **Expandable FAQ Accordion**: Smooth CSS grid-based accordion.
- **Interactive Appointment Booking**: Form handling with immediate feedback and toast notifications.

## 🛠️ Local Development
To run this project locally, simply open `index.html` in your browser or run a local web server:
```bash
# Using Node.js
npx serve .

# Or using Python
python -m http.server 3000
```
